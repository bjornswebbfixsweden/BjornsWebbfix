ÖPPNA BOKNINGSKALENDERN

Meddelandeförfrågan

Vid sändning av meddelande behandlas personuppgifter av Björns Webbfix för att kunna besvara ärendet. Data skickas via tjänsten Web3Forms direkt till den e-post som hanterar kundärenden. Endast uppgifter som krävs för att assistera i ärendet sparas.

Integritetspolicy

Här följer information om hur digital data hanteras:

  • Ändamål: Namn och e-post samlas in uteslutande för att besvara förfrågningar eller administrera bokningar.
  • Analys: Google Analytics används i anonymiserad form för att förstå besöksflöden och förbättra användarupplevelsen.
  • Bokningar: Tidsbokning sker via Setmore enligt gällande säkerhetsrutiner.
  • Tredjepart: Web3Forms används för teknisk leverans av meddelanden. Ingen data säljs vidare till tredje part.
  • Lagring: Korrespondens sparas så länge det krävs för att fullfölja samarbetet eller tills begäran om radering inkommer.
